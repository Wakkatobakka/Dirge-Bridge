# v0.2.4 status

v0.2.4 is the current device-tested control baseline.

Observed working on the owner's Samsung Galaxy S25 Ultra / Android 16:

- Lost Episode boot and 3D rendering
- English text data import/use
- music, voice, menu sounds, interaction sounds, and gameplay SFX
- short-audio completion/channel recycling repair
- pause/resume audio synchronization
- touch movement and roll assist
- field camera left/right
- first-person weapon aim left/right using native game input
- original game checkpoint storage/backups

The full game has not yet been exhaustively compatibility-tested from start to finish. Future changes should be narrowly scoped and regression-tested against this baseline.
