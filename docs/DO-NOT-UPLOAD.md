# Do not upload these files

Keep these outside GitHub unless a future rights review explicitly says otherwise:

- Lost Episode game files and SD packs
- private English-patched game-data ZIPs
- translation patch files unless redistribution permission is confirmed
- signing keystores and passwords
- old private preservation ZIPs that contain signing material
- raw device recordings/reports unless intentionally selected for publication

The GitHub-safe starter package was created specifically to avoid those categories.
